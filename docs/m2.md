# M2 Record

> 2026-10-28. Goal (OUTLINE §7, due 11/1): a tool-calling loop with guardrails, a Translator Agent, metering, a tracing tool, and an eval harness (`eval/run.py`, manifest, sacreBLEU chrF / BLEU). `baseline` is scored on 3 pages, and the Translator Agent runs on the same 3 pages as a smoke test, not as a reported config.

## How to run

See "Run it" in the README: `eval/run.py --config baseline` or `--config translator`, and the optional tracing in a local Phoenix. `scripts/m2_tool_smoke.py --dry-run` (add `--repair-check` for the repair request) shows what the agent loop sends without sending it.

## What was built

M2 was built as eight tasks, each one PR with written acceptance criteria, an execution report and an independent review ([docs/workflow.md](workflow.md)). Each task was followed by a docs PR.

| Task | What it added | PR |
|---|---|---|

| Run status and cost | A Run's cost is NULL, never a partial sum, when any call had no usage; a reply with region ids that are not on the page fails the Run; an exception after the Run row exists marks it failed (`RunCrashed`) instead of leaving it `running`; the eval harness reports what failed pages cost | #9 |
| Stale errors and recovery | A Run that succeeds on its retry stores no error; when marking a crashed Run failed fails too, the caller still gets `RunCrashed` with the Run's id; no calls, or no Runs, cost 0.0 | #11 |

## Design decisions

The reasons are in [OUTLINE.md §8](../OUTLINE.md#8-decisions). The short form:

- **References use OpenCC `t2s`.** It converts characters only. `tw2sp` was rejected because it also rewrites the human translator's wording.
- **Unknown usage is never 0, and that now covers failures too.** A request that raised, or a response that could not be read, is still a call, metered once. The SDK's own retries are off, so every request sent is one call the `Meter` sees. A Run, and an eval total, show a NULL cost rather than a partial sum.
- **One attempt or step per call.** A `baseline` Run keeps one attempt per call, failed ones included. An agent run keeps one step per model call.
- **The agent loop is LangChain's `create_agent`, but the model layer is ours.** LangChain's provider models would bypass the `Meter`, retry by default, and, by community reports, drop DeepSeek's `reasoning_content` on tool-call turns. LangChain stays inside `agents/`, behind a plain result, so it can be replaced.
- **Guardrails: the §3.4 set plus one.** The set is the Step limit, the token budget, duplicate-call detection, and the model's mistakes passed back as tool results. The addition: a reply cut off for any reason other than `stop` or `tool_calls` is never taken as an answer. Other checks wait until traces show a need (`IDEAS.md`).
- **The Translator Agent sees exactly `baseline`'s input.** The user message is the same; only the system prompt and the tool differ. A bad answer gets one repair call. After that, or after `step_limit` or `incomplete`, the page falls back to `baseline` with a budget of its own; the Run records it and the eval counts it. After a provider error or a spent budget nothing more is sent.
- **`flag_uncertain` moved to M3.** A flag needs somewhere to be stored and someone to read it (the Reviewer, the editor).
- **Tracing in a local Phoenix, kept replaceable.** No account, no cost, and traces kept as long as needed for the report's links. The code uses only OpenTelemetry and OpenInference, and Phoenix is one exporter function. `hide_input_images` was not enough to keep page images out of spans, so a redacting exporter removes images and the API key from every span.

## Not done / not verified

- **Quality.** Only 3 pages were translated with each config, so there is no claim about quality. The dev split comes in M4.
- **The repair and fallback paths.** They ran only against scripted providers in tests. Against DeepSeek, only the repair request's shape was checked, once.
- **The editor and the API.** They still run `baseline` only; nothing in the frontend changed in M2. The API under uvicorn with tracing on was not run against a real provider.
- **Trace export and proxies.** The exporter honours `HTTP_PROXY`, so with a proxy set, `NO_PROXY=localhost,127.0.0.1` is needed to keep traces local. A fix is planned.
- **Trace IDs for early failures.** A page that fails before its Run exists still records a trace, but its eval row has no trace ID.
- **Carried over** (`IDEAS.md`): a Run stays `running` if its process is killed; there is no server-side guard against a double click; eval outputs are written only after the last page.
