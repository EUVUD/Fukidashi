## 诊断（另花 2 次调用，已记入 `runs/usage.jsonl`）

1. **图片确实被用上了。** 同样的请求去掉图片后 input 是 331 tokens，所以这张 830×1170 的图约 591 tokens，比 `docs/openmantra.md` 里的粗估（约 1.3k）少一半多。
2. **模型能看懂画面，但细节不可靠。** 让它描述这一页：吵架的内容（欠债）、砸拳头、女性在吼、刺猬头男性，都说对了；但它说有 3 个分格，实际是 4 个，也把左下分格里露脸的人认错了。
3. **thinking 是开着的，但这种短任务想得很少。** reasoning tokens 在 `usage.completion_tokens_details.reasoning_tokens` 里（不带图片的那次是 296 个 output 里占 227 个），已经算在 output tokens 里。回复里的 `reasoning_content` 字段也有内容。
4. **JSON mode 和 thinking 可以同时开。** 第一次调用就返回了合法 JSON。
5. **DeepSeek 的缓存字段：** 除了标准的 `prompt_tokens_details.cached_tokens`，还有 `prompt_cache_hit_tokens` / `prompt_cache_miss_tokens`。目前计费按单一 input 价格算，有缓存命中时会高估，不会低估。

## 观察（给 M2、M3 用）

- **人名音译不一致：** レーネ 在这次翻成「蕾妮」，参考译文是「蕾娜」，让模型描述画面时它又写成「蕾内」。这正是 KB（Character Profiles）和 gold glossary 要解决的问题。
- **语气：** id 1 原文是在吼，「我都说了不知道吧！」的「吧」太软；不带图片的那次翻成「我都说了我不知道啊！」更好。只有两次样本，不能下结论。
- **成本：** 按实测，`baseline` 每页约 0.9k input + 0.3k output tokens，按高峰价约 $0.0006 / 页，全书 214 页约 $0.13。
